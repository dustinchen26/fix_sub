# 🎬 SRT 字幕錯字修正工具 (SRT Subtitle Auto-Fixer)

https://dustinchen26.github.io/fix_sub

一個基於 HTML5 + Tailwind CSS + JavaScript 打造的純前端 SRT 字幕檔錯字快速修正工具。

---

## ✨ 核心功能與特色

- 📁 **拖曳即時解析**：支援直接將 `.srt` 字幕檔拖曳至頁面，自動讀取與解析時間軸與文本內容。
- ⚡ **純前端高隱私**：所有檔案處理與替換皆在本地瀏覽器完成，字幕資料不會上傳至任何伺服器。
- 📚 **內建豐富字典**：針對政治辯論、在地地名（高雄/台北等）、專有名詞及常見台國語誤植，預設收錄大量的校正規則。
- 🔍 **即時對比預覽**：直觀顯示「原錯字（紅標刪除線）」與「修正字（綠標高亮）」，並提供關鍵字搜尋過濾功能。
- ✍️ **彈性手動微調**：點擊預覽區域的字幕文字即可直接進行二次手動編輯，系統將自動同步計算修正統計數。
- 📥 **一鍵導出與複製**：支援導出正確格式的 `.srt` 檔案或將全文複製至剪貼簿。

---

## 🚀 快速開始

本專案採用**單一 HTML 檔案設計**，無須安裝額外的環境（如 Node.js 或 npm）。

### 1. 開啟方式
直接點擊下載專案中的 `srt.html`（或將其命名為 `index.html`），並以任意現代瀏覽器（Chrome, Edge, Safari, Firefox）開啟即可使用。

### 2. 使用步驟
1. **上傳檔案**：將你的 `.srt` 檔案拖曳至頂部上傳區，或點擊選擇檔案。
2. **自動校對**：系統會自動對照內建字典進行批次替換，並在右側面板即時呈現結果。
3. **對比與修飾**：使用搜尋框查找特定的句段，有需要時可直接在輸入框內手動進行調整。
4. **下載匯出**：確認無誤後，點擊右上方「下載修正後的 SRT」按鈕，或點擊右側「複製修正後全文至剪貼簿」。

---

## 🛠️ 如何擴充或修改錯字字典？

你可以直接在 `index.html` (或 `srt.html`) 的 JavaScript 程式碼中擴充或編輯替換規則字典。

在檔案中找到 `REPLACE_MAP` 常數宣告處：

```javascript
const REPLACE_MAP = {
  // 格式： "原本的錯字": "修正後的正確字"
  "到陸思誠市長": "到陳其邁市長",
  "高雍": "高雄",
  "才化法": "財劃法",
  // 可以在此處新增你自訂的校正對
  "你要搜尋的錯字": "正確替換字",
};
```
